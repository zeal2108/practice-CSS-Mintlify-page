# Practice-CSS-Mintlify-page

This repository offers a **desktop-only static layout clone of the "www.mintlify.com" landing page**, created using **only HTML and CSS**.

The project focuses purely on **structure, layout, typography, spacing, and visual hierarchy**, it is a desktop-only non-responsive web-page without any kind of interactivity.

[Click here to view the demo screenshot ->](Full-screenshot-mintlify.png)

[Live Web-page link ->](https://practice-css-mintlify-page.vercel.app/)

---

## Project Goals

The primary goal of this clone is **practice**, not replication for production use.

Specifically, this project was created to:

- Strengthen understanding of **semantic HTML**
- Improve **CSS layout skills** (Flexbox / Grid)
- Practice **modern typography**
- Analyze and recreate **spacing, alignment, and visual structure**
- Learn how polished landing pages are structured at a CSS level

No frameworks, pre-processors, or libraries were used. 
Everything is written from scratch from a learner's perspective.

---


##  Technologies Used

- **HTML5**
  - Basic structure tags
  - Modern semantic HTML 
- **CSS3**
  - Flexbox
  - CSS Grid

## Fonts Used

The project uses fonts inspired by Mintlify’s design to achieve a clean, modern, developer-focused aesthetic.

> Fonts are loaded via **Google Fonts**

- **Primary Font:**
 
  `Plus Jakarta Sans` : used for body text, headings, and UI elements. Chosen for its readability and modern sans-serif feel
	
  `JetBrains Mono` : used for small headings.

  `Geist Mono` : used for small headings.
 
*(Exact font usage can be verified in the CSS file.)*
